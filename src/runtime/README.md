# Runtime verification — this is the app

If a use is on the phone, a walk here is that use. The Deployment Check `runtime-doors` runs **every** walk on **this** deploy URL. Green means the app worked. It does not mean the door returned headers.

**Law**

- One sitting, send, **wait for the mouth**, read the tape, next beat.
- A generate miss / `kind=status` that says error **fails**. `?? · run error` on the phone is a red check.
- Do not grade whether Travis’s reply was clever. That is like. Do grade: he spoke, or the miss is the named unwired line.
- Dest to a Cursor seat: wait for the leave to start. Do **not** wait for that seat’s essay. Do fail if Travis’s mouth (035 wrap) died.
- One test-operator cookie resumes one live room. The suite runs **sequentially**. Each walk starts a fresh sitting (`End` + open) except the come-back resume beat.
- Do not invent a Scenario Graph. Add a walk when the app gains a use.
