## 2026-08-25 19:42 UTC — Lived Cursor friction (what Travis replaces)

**Kind:** Type B seed + Type A (why the face exists). Founder describing today’s PM-chat path on the phone.

**Founder wording — today’s loop:**

> What I would usually have done is to get into Cursor, pick the PM chat, and begin talk — click the voice or microphone icon so I can start talking into the chat. One of the big issues with that is that I can’t speak more than four minutes unless all of what I said would be lost. So I have to keep it less than four minutes… All of this is just transcribed into text so that when I’m done and I stop the recording I have to wait for all of it to transcribe into text, and then… I then send that message… And then I have to keep checking back my phone to see if it’s done responding. Have to read it because there’s no… way to like listen to what it’s generated… Occasionally, I would ask for an image or some reference… and it would show that in the chat… in the PM chat, something we do often is to generate plates after we’re done… about what we’re working on.

**Friction list (founder; not a substitute flag):**

1. Open Cursor → find the right chat (PM).  
2. Mic turn ≤ ~4 minutes or **lose the whole utterance**.  
3. Stop → **wait for full transcription** before send is possible.  
4. Manual send.  
5. **Poll the phone** for “done responding.”  
6. **Read** only — no listen-back.  
7. Images / **plates** sometimes land in chat — must still work here; think through that on the smartphone plate.

**Wanted removal (founder):** if the four-minute hard stop can go away, great — keep talking without losing the turn.
