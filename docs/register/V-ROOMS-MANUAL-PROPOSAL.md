### V2 — Create a room

**I’m going to generate a plate about:** naming the room, and who is in it at birth.

**Why it’s its own plate:** a room now outlives a session. Naming + founding roster is a form we have never drawn. Not the index.

**On it:** name field. Who starts in (quiet picks, not a twelve-control stack). One loud: Create.

**Not on it:** model/repo spend (that’s minting an *agent*, V4). Cost dashboard. Delete.

### V3 — Room roster (door)

**I’m going to generate a plate about:** who is in this room, and **add / remove by hand** — same effects Travis can cause.

**Why it’s its own plate:** this is where nothing-is-Travis-only lands hardest. Not always-on on Voice. A door from inside the room.

**On it:** the list. Add someone. Remove someone from *this room*. Quiet. Join/leave as a change on this list — not its own PNG.

**Not on it:** minting a new agent from scratch (V4). Deleting an agent forever (manual-only; Travis proposes, you execute — no loud trash). Twelve tools.

### V4 — Create an agent

**I’m going to generate a plate about:** model, repo, starting ref as **pickers**, and the spend — the one place the product spends money on purpose.

**Why it’s its own plate:** Engineer can list models and repos. This is a form, not a Voice chrome row.

**On it:** three pickers. A muted cost/spend line so you see it *as you create*. One loud: Create.

**Not on it:** room index. Forever-delete. A cost history dashboard (spoken, or later).

### V5 — Room face, N seats (Talk log)

**I’m going to generate a plate about:** the room when it is **more than three people** — via-pill, thought strip, queue rows, narration as a receipt (quieter than speech).

**Why it’s its own plate:** every planted surface assumes PM · SA · Engineer. The revision is real. Showing four-plus is the only way the change is visible.

**On it:** Talk log. More than three seats. Via-pill with a free-text label that isn’t a three-letter code. Thought strip that doesn’t pretend the cast is three. Queue row can ride if it doesn’t fight. Narration stays a receipt (U1 law).

**Not on it:** Type composer. Voice orb. Don’t put Voice + Type on one PNG.

**Optional second PNG (only if you want it):** **V5b** — Type, same N-seat room, `@` menu that scrolls. D3 already has `@` for four titles; this is only if the *unbounded* menu needs to be seen. I would not print V5b unless you say so.

### V6 — Work in flight (door)

**I’m going to generate a plate about:** what’s running, for whom, and that you can leave — the manual counterpart to dispatch-and-don’t-wait.

**Why it’s its own plate:** Engineer named this as a parity gap and then didn’t put it on the candidate list. If Travis can send and walk away, you have to be able to *see* what’s in flight without twelve always-on bars on Voice.

**On it:** a quiet sheet/door. What’s running. Who. You can go back to the room.

**Not on it:** a second barge button (003 already). Summarize. Cost history.
