## A. Walk back in

**Do:** Leave the room (or wait). Come back. Type:

```
Where are we? What was the last thing we discussed?
```

**Expect:** He names the last real discussion, not only “you said hey.” Not a blank card. Not `Travis error: Cannot use import statement outside a module`.

```

```

**Expect:** A dest leaves. Body is the ask plus the print. He does not create a person. He does not dest the instruction only.
