## What stays the same across modes

The board and every product plate share **one geometry.** Across Mission and Carbon the only change is **tokens** (page, type, accent). Not layout. Not icon shapes. Not type sizes. Not spacing. Not where things sit.

Locked from Engineer kit:

- Presence orb — four states: resting · listening · speaking · paused
- Seat marks — same circles, same letters (PM · SA · ENG · TRV). Semantic ring colors may stay; mode does not redraw them
- Pills / chips — same outline and radius
- Stroke icons — mic, mute, send, `@`, chevrons, close, play, stop, wave
- Type scale — Display 32 · Title 22 · Body 16 · Meta 12
- Spacing — 4pt base (4 / 8 / 12 / 16 / 24 / 32)

Locked from T-set:

- **TRAVIS** wordmark = that wide grotesque, every time the logo appears. That is the logo font. Not Carbon’s tracked wordmark. Not serif C-set Travis.

Body / UI copy: the shared geometric sans both sides already used (Poppins / Montserrat-class). Not a new face.
